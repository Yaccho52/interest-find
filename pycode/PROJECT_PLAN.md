# 香港文化活动推荐系统：初步方案

## 目标与范围

帮助香港居民及访客从康文署公布的活动中发现符合兴趣、日期和场地偏好的节目。
全部建模使用现有活动资料，不生成虚构用户评分，不做时间序列预测。
日期仅用于活动可用性筛选。项目主体为 Python。

## 官方来源与快照

- 数据入口：https://data.gov.hk/en-data/dataset/hk-lcsd-event-event-cultural
- 字段说明：https://www.lcsd.gov.hk/datagovhk/event/data_dictionary.pdf
- 节目：https://www.lcsd.gov.hk/datagovhk/event/events.xml
- 日期：https://www.lcsd.gov.hk/datagovhk/event/eventDates.xml
- 场地：https://www.lcsd.gov.hk/datagovhk/event/venues.xml
- 下载日期：2026-10-19（Asia/Shanghai）。原文件保存在 data/raw。

已下载快照包含 1,103 个活动、165 个场地。活动 ID 无重复，场地关联完整。
中文详情缺失 922 条，英文详情缺失 945 条，中文价格缺失 595 条。
只有 68 个场地具备经纬度，不能默认全部支持距离推荐。
上述数量来自当前快照，不代表完整香港活动市场。

## 产品功能

1. 输入兴趣文字，或选择若干喜欢的活动，获得相似活动。
2. 按日期、场地、节目类别筛选。
3. 展示标题、原始价格文字、活动日期、推荐理由及官方详情链接。
4. 通过主题聚类探索原本没有搜索到的节目。
5. 在推荐结果中兼顾相似度和多样性。

价格缺失标记为未知，不当作免费；复杂票价保留原文，未可靠解析前不做硬预算承诺。
部分日期为 20990101，需要标记审查，不能作为真实远期活动日期。
新用户输入偏好不属于新增训练数据，无需开展问卷。

## 模型与个人实现

- 基线：简单关键词匹配。
- 核心：中文字符 n-gram、英文词项的 TF-IDF 与余弦相似度。
- 用户兴趣向量：将所选活动向量加权组合，实现内容推荐。
- 聚类：K-means 用于主题探索，不用 elbow method 作为主要方法。
- 多样性重排：MMR，比较相关性与重复程度之间的取舍。
- 可选分类：用标题与详情预测官方类别；类别不能作为分类输入。

核心公式与迭代过程使用 Python/NumPy 实现，库模型用于核对或比较。
是否加入分类取决于类别分布和去重后样本量，不能为了展示方法数量强行加入。

## 验证与局限

- 推荐：报告目录覆盖率、列表内部相似度和重复情况；类别一致性只是代理指标，不能声称是真实满意度。
- 分类：报告 macro-F1、每类指标和混淆矩阵；极小类别不强行拆成训练测试集。
- 聚类：比较不同初始化与主题可解释性。
- 相同或高度相似节目应按组划分，避免重复标题跨训练集和测试集造成泄漏。
- 中文简繁体处理需明确；词面匹配不能宣称具备任意跨语言语义理解。
- 没有用户点击、评分或购票记录，因此不采用协同过滤作为主模型。
- 数据详情稀疏，标题和类别较关键；不擅自用 AI 生成的详情填充真实数据。
