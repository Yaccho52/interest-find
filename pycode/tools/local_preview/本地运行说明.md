# 在你的电脑运行拾趣香港

## 最简单的启动方式

双击项目文件夹中的 **启动网站.bat**。

它会使用你电脑已有的 Python，打开浏览器并显示网站。无需安装 Flask、Node.js 或其他网站依赖，也不需要登录或联网。
使用期间保留启动窗口；按 Ctrl+C 或关闭窗口停止网站。活动详情跳转至官方网站时需要网络。

默认地址为 http://127.0.0.1:8765/ 。如果端口已占用，会自动寻找其他可用端口，以窗口显示的地址为准。
网站仅允许本机访问。不要直接双击 index.html，浏览器对本地文件的数据加载有限制。

## 用命令启动

在项目根目录打开终端：

```powershell
python -X utf8 run_local.py
```

也可以指定端口：

```powershell
python -X utf8 run_local.py --port 8888
```

## 更新模型和网站

当前已经包含生成好的模型与网页数据，平时不需要重新训练。
如果修改了数据或建模代码，关闭模型运行中的其他程序后，双击 **更新模型和网站.bat**。
它依次训练模型、检查关键行为、导出网站数据；不会自动下载数据或安装软件。
更新后刷新网页即可。这些本地更新不会自动发布到在线网站。

建模使用当前已安装的 NumPy、pandas；启动网站本身只使用 Python 标准库。

## 文件夹要一起保留

- run_local.py 与启动网站.bat：本地启动入口。
- site/dist/：网页、配图与推荐数据，启动时必需。
- data/、output/model/ 和模型代码：重新建模时必需。

可以移动整个项目文件夹，启动器会自动定位网页目录。
