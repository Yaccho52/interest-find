# 香港活动推荐模型

使用项目现有 Python 环境及已安装的 NumPy、pandas，无需安装 scikit-learn。
所有新增建模代码均有中文注释，主要环节用连续两行 # 标题分段。

## 运行顺序

1. `python -X utf8 model_events.py`：训练并保存模型及评估结果。
2. `python -X utf8 check_models.py`：验证公式和主要行为。
3. `python -X utf8 recommend_events.py --query "CS2 BLAST"`：查询推荐。

更多示例：

```text
python -X utf8 recommend_events.py --query "足球" --on-date 2026-10-19 --as-of 2026-10-19
python -X utf8 recommend_events.py --query "音樂 music" --as-of 2026-10-19
python -X utf8 recommend_events.py --liked lcsd:188359 --as-of 2026-10-19
python -X utf8 recommend_events.py --query "exhibition" --venue "圖書館"
```

默认参考当天香港日期；使用 `--as-of` 可复现旧快照。`--all-dates` 包含历史和日期未知的目录活动。
类别可通过 `--category esports` 或 `--category football` 等限定。
票价保留原文字，不承诺当前可购买、不进行未经核实的预算筛选。

## 输出

- output/model/model.npz：TF-IDF 目录向量、IDF、聚类中心与标签。
- output/model/vocabulary.json：中文字符片段及英文词项。
- output/model/catalog.csv：1,231 条统一目录记录与聚类标签。
- output/model/results.json：运行环境、输入校验值、评估及示例。
- output/model/建模报告.md：可阅读的第一轮建模报告。

## 方法及解释

TF-IDF 使用 `tf = 1 + log(词频)`、`idf = log((1+文档数)/(1+文档频次)) + 1`，之后 L2 归一化。
余弦相似度用于文字和已喜欢活动的匹配。MMR 在前 100 个候选中兼顾相关性与不重复性，排除同标题组。
球面 K-means 对文本主题进行无监督聚类；固定 8 簇并比较 3 个初始化，不涉及时间序列或 elbow method。
少量中文简繁和领域词别名为显式人工规则，不宣称通用翻译或深层语义理解。
查询明确提及体育类别时，可使用目录类别加分；类别并未进入文本训练或检索代理评估。

评估采用目录中 100 个标题作为查询，排除相同标题，检查同类别 P@5、覆盖率、列表内部相似度。
这是弱代理评估，不是用户满意度、分类准确率或未来泛化能力；没有虚构评分或问卷。
模型尚未超过关键词基线的同类别 P@5，报告保留真实结果；不同方法的取舍需要解释。

日期只作筛选，BLAST 使用 11 月 13–15 日的现场观众日期。当前没有网页界面。
AI 协助了代码实现、分析流程与文档，提交报告时须明确声明，答辩前需掌握每一步实现。
