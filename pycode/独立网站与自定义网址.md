# 把拾趣香港部署为你自己的网站

独立版本已经准备好，位于 independent_site 文件夹。
它包含网页、活动数据和配图，不包含 ChatGPT 托管配置，不调用 OpenAI API，不要求访客登录。
当前还没有发布到你的第三方托管账号，也还没有注册或绑定你的域名。

## 第一步：在你自己的账号中发布

1. 在 https://app.netlify.com 注册并登录你自己的账号。
2. 打开 https://app.netlify.com/drop 。
3. 将整个 independent_site 文件夹拖入上传区。
4. 发布成功后，平台会分配一个 netlify.app 网址。
5. 在该项目设置中修改项目名称，可更改默认网址的名称部分；需要是未被占用的名称。

不需要上传整个 pycode 文件夹，不需要在线安装 Python 或 NumPy。
ZIP 备份位于 output/independent/；使用拖拽发布时先解压，再上传解压后的完整网站目录。

## 第二步：选择你想要的网址

有两种选择：

- 使用平台默认子域名：名称.netlify.app。名称是否可用，以平台检查结果为准。
- 使用你拥有的独立域名：例如 www.你的域名.com。需要先注册并持有该域名，再绑定到网站。

独立域名由域名注册商按自己的规则收费及续费；仅修改网站名称不会自动获得一个 .com 域名。
示例域名只是说明格式，没有检查或购买任何域名。

## 第三步：绑定自己的域名

1. 在 Netlify 项目的域名管理中添加你拥有的域名。
2. 按页面给出的准确 DNS 记录，在域名注册商处完成配置。
3. 等待域名验证与 HTTPS 证书就绪后，用新网址检查页面、图片和活动数据。

DNS 记录值取决于最终网站和域名，不要直接复制示例 IP 或其他网站的记录。

## 更新网站

运行 build_website.py 更新数据后，再运行 package_independent.py 刷新独立目录。
把更新后的 independent_site 目录上传到你已有项目的部署区域，不要每次新建一个网站。
